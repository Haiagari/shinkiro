# Compliance

OzyRecon is designed for authorized validation, traceability, and audit-ready reporting.

## Guardrails

- explicit scope checks before active work
- protected runtime and API access
- signed evidence and session traces
- no blind or unbounded execution
- AI limited to analysis and summarization

## Framework alignment

- access control and scoped runtime access
- secure logging and reviewability
- evidence-backed reporting
- operational visibility for sessions and diffs

## Non-goals

- offensive payload generation
- active exploit execution
- EDR/WAF evasion as a product feature
