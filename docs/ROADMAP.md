# 🗺️ OzyRecon Strategic Roadmap

OzyRecon is an evolving platform. Our mission is to build the most intelligent, surgical, and professional reconnaissance engine in the open-source ecosystem.

Current operational work is focused on hardening and contract closure for the existing v6.0 engine. The product roadmap below remains the source of truth for feature phases.

## 🏁 Phase 1: Foundations (v1.0 - v5.0) - [COMPLETED]
- [x] Basic subdomain discovery and service fingerprinting.
- [x] Human-in-the-loop (HITL) initial implementation.
- [x] SQLite persistence layer for session state.

## ⚡ Phase 2: Intelligence & Integrity (v5.7) - [COMPLETED]
- [x] **Knowledge Graph v2**: D3.js visualization of target relationships.
- [x] **Evidence Engine**: SHA256 cryptographic signing of findings.
- [x] **Professional Reporting**: High-fidelity executive reports.

## 🗡️ Phase 3: The Phantom Blade (v6.0) - [COMPLETED]
- [x] **Chameleon Stealth**: TLS Fingerprinting evasion via `curl_cffi`.
- [x] **Logic Brain**: Automated correlation of review paths in the Knowledge Graph.
- [x] **Surgical Prober**: Zero-noise evidence validation engine.

## 🧠 Phase 4: Intelligent Engine (v7.3 Alpha) - [COMPLETED]
- [x] **Contextual Recon**: ASN, Organization, and Cloud enrichment.
- [x] **Snapshot Memory**: Historical diffing and novelty detection.
- [x] **Semantic Classifier**: Inferred roles and business impact mapping.
- [x] **Evidence Layer**: HTTP headers and response capture.
- [x] **Takeover Hunter**: DNS lineage and automated takeover detection.
- [x] **Chameleon v2**: Refined stealth with identity rotation.
- [x] **Adaptive Planning**: Target-aware execution profiles.
- [x] **Graph v7**: Relationship-first data model.

Phase 4 is intentionally constrained to safe autonomy. It improves prioritization, correlation and review workflows without adding exploitation automation.
