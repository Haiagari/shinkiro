# 🗺️ OzyRecon Strategic Roadmap

OzyRecon is an evolving platform. Our mission is to build the most intelligent, surgical, and professional reconnaissance engine in the open-source ecosystem.

## 🏁 Phase 1: Foundations (v1.0 - v5.0) - [COMPLETED]
- [x] Basic subdomain discovery.
- [x] Human-in-the-loop (HITL) initial implementation.
- [x] Port and service fingerprinting.
- [x] SQLite persistence layer.

## ⚡ Phase 2: Intelligence & Integrity (v5.7 - Current)
- [x] **Knowledge Graph v2**: D3.js visualization of target relationships.
- [x] **Evidence Engine**: SHA256 cryptographic signing of findings.
- [x] **Professional Reporting**: High-fidelity HTML executive reports.
- [x] **CI/CD & Security**: GitHub Actions with Bandit SAST.

## 🧠 Phase 3: The Brain (v5.8 - v5.9) - [IN PROGRESS]
- [ ] **AI-Remediation (LLM)**: Automated remediation advice using local Ollama or GPT-4 APIs.
- [ ] **Multi-node Scanning**: Distributed task execution across different IPs.
- [ ] **TUI Dashboard**: Interactive Terminal UI using `Rich` and `Textual`.
- [ ] **JWT & API Validation**: Specific modules for surgical API security testing.

## ☁️ Phase 4: Enterprise Scale (v6.0+) - [PLANNED]
- [ ] **Cloud Native Deployment**: Full Kubernetes support and Helm charts.
- [ ] **RBAC (Role Based Access Control)**: Multi-user support with different permission levels.
- [ ] **Corporate Integrations**: Direct findings export to Jira, ServiceNow, and Slack.
- [ ] **Mobile Interface**: Lightweight Progressive Web App (PWA) for managing hunts on the go.
