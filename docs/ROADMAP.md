# 🗺️ OzyRecon Strategic Roadmap

OzyRecon is an evolving platform. The current product reality is the v8.3.2 Enterprise Baseline, and the active work is focused on runtime stability, contract closure, and documentation alignment rather than inventing new core phases.

This roadmap is kept as the historical evolution of the engine plus the next planned horizon.

## 🏁 Phase 1: Foundations (v1.0 - v5.0) - [COMPLETED]
- [x] Basic subdomain discovery and service fingerprinting.
- [x] Human-in-the-loop (HITL) initial implementation.
- [x] SQLite persistence layer for session state.

## ⚡ Phase 2: Intelligence & Integrity (v5.7) - [COMPLETED]
- [x] **Knowledge Graph v2**: D3.js visualization of target relationships.
- [x] **Evidence Engine**: Ed25519 cryptographic signing of findings.
- [x] **Professional Reporting**: High-fidelity executive reports.

## 🗡️ Phase 3: The Phantom Blade (v6.0) - [COMPLETED]
- [x] **Chameleon Stealth**: TLS Fingerprinting evasion via `curl_cffi`.
- [x] **Logic Brain**: Automated correlation of review paths in the Knowledge Graph.
- [x] **Surgical Prober**: Zero-noise evidence validation engine.

## 🧠 Phase 4: Intelligent Engine (v7.0) - [COMPLETED]
- [x] **Contextual Recon**: ASN, Organization, and Cloud enrichment.
- [x] **Snapshot Memory**: Historical diffing and novelty detection.
- [x] **Semantic Classifier**: Inferred roles and business impact mapping.
- [x] **Evidence Layer**: HTTP headers and response capture.
- [x] **Takeover Hunter**: DNS lineage and automated takeover detection.

## 🔥 Phase 5: Elite Intelligence (v8.0) - [COMPLETED]
- [x] **Formal Inference Engine**: YAML-based rule formalization and logic tracing.
- [x] **Digital Evidence Integrity**: Ed25519 cryptographic signing for verifiable Chain of Custody.
- [x] **Actionable Graphs**: Decision-guidance visualization with Critical Path identification.

## 🛡️ Phase 6: Operational Hardening (v8.3.2) - [COMPLETED]
- [x] **Advanced API Auth**: Hashed multi-key registry with granular RBAC (Scopes).
- [x] **SSRF Pro Shield**: Anti-DNS Rebinding and private IP range blocking.
- [x] **Lifecycle Control**: Managed task tracking and scan cancellation endpoints.
- [x] **AI Analyst Layer**: Narrative impact assessment and mitigation advice via LLM bridge.
- [x] **Storage Management**: Automated TTL cleanup and log rotation.

## 🚀 Phase 7: Hyperscale Ecosystem (v9.0) - [PLANNED]
- [ ] **Distributed Infrastructure**: Migration to PostgreSQL and Redis-based task queue support.
- [ ] **Multi-Node Swarm**: Synchronized discovery across multiple Sentinel nodes.
- [ ] **SIEM Push Gateway**: Proactive alerting via webhooks and native SIEM connectors.
- [ ] **Forensic Dashboard**: Advanced UI for verifiable evidence audit and bundle validation.

## Current Focus

- Keep the v8.3.2 runtime stable
- Preserve the bootstrap/auth/session lifecycle contract
- Keep docs and implementation in sync
- Treat archive docs as historical references, not active plans
